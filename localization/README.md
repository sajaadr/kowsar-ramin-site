# Localization package

This directory is the candidate authority and human-review surface for the Kowsar & Ramin multilingual expansion.

- `LOCALIZATION_CANONICAL.json` — machine-readable candidate authority.
- `TRANSLATION_REVIEW.md` — human review surface.
- `TRANSLATION_STYLE_GUIDE.md` — voice, variant and terminology rules.
- `I18N_QA_RUBRIC_100.md` — 25 domains × 4 criteria.
- `I18N_QA_REPORT.md` — 10-wave internal QA record.
- `I18N_IMPLEMENTATION_PLAN.md` — implementation/promotion plan.
- `../scripts/check-i18n.py` — deterministic structural validator.

The package is intentionally staged on a non-production branch. Internal translation scores are review signals, not a substitute for native-speaker certification.
