# I18N QA Rubric — 100 Criteria

Twenty-five domains × four criteria = **100 explicit review criteria**. A production candidate should have no relevant internal review score below 9.8/10, while deterministic checks must pass outright.

## 1. Semantic fidelity
- 1.1 Core proposition unchanged
- 1.2 No omitted service/opportunity meaning
- 1.3 No added promises or qualifications
- 1.4 Metaphor keeps practical intent

## 2. Intent preservation
- 2.1 CTA intent unchanged
- 2.2 Contact intent unchanged
- 2.3 Referral/share intent unchanged
- 2.4 Accessibility action intent unchanged

## 3. Grammar
- 3.1 Sentence grammar correct
- 3.2 Article/case use correct
- 3.3 Verb tense/aspect correct
- 3.4 Agreement correct

## 4. Morphology
- 4.1 Inflections correct
- 4.2 Case endings correct
- 4.3 Plural/singular correct
- 4.4 Possessive forms correct

## 5. Syntax
- 5.1 Natural word order
- 5.2 No source-language calques
- 5.3 Parallel lists balanced
- 5.4 Hero split remains grammatical

## 6. Idiomaticity
- 6.1 Sounds native rather than translated
- 6.2 Common collocations
- 6.3 Natural CTA verbs
- 6.4 Natural social/share wording

## 7. Common vocabulary
- 7.1 Avoid rare synonyms
- 7.2 Avoid bureaucratic words
- 7.3 Avoid technical jargon
- 7.4 Prefer broadly understood terms

## 8. Tone
- 8.1 Warm
- 8.2 Professional
- 8.3 Modest/non-hyped
- 8.4 Human and collaborative

## 9. Plain language
- 9.1 Easy first-read comprehension
- 9.2 Short clauses
- 9.3 Concrete verbs
- 9.4 No unnecessary abstraction

## 10. Concision/UI fit
- 10.1 CTA brevity
- 10.2 Service-line density
- 10.3 Metadata length reasonable
- 10.4 Status-message brevity

## 11. Terminology consistency
- 11.1 Same concept translated consistently
- 11.2 Bookings distinct from commissions
- 11.3 Wellbeing consistent
- 11.4 Craft/carpentry distinctions retained

## 12. Professional appropriateness
- 12.1 Suitable for work inquiries
- 12.2 No childish register
- 12.3 No over-formality
- 12.4 No accidental medical/legal implication

## 13. Cultural neutrality
- 13.1 No country stereotypes
- 13.2 No honorific assumptions
- 13.3 No flag dependence
- 13.4 No unintended political/ethnic framing

## 14. Inclusivity/respect
- 14.1 Gender-neutral where source is neutral
- 14.2 Respectful address
- 14.3 No exclusionary phrasing
- 14.4 Volunteer wording non-coercive

## 15. Brand/name integrity
- 15.1 Kowsar spelling preserved
- 15.2 Ramin spelling preserved
- 15.3 Together handled consistently
- 15.4 Instagram/WhatsApp unchanged

## 16. Unicode/typography
- 16.1 NFC-safe text
- 16.2 Correct script characters
- 16.3 No mojibake risk
- 16.4 Font coverage considered

## 17. Punctuation
- 17.1 Locale-appropriate punctuation
- 17.2 Middle dots preserved where intended
- 17.3 Quotes/apostrophes correct
- 17.4 Colon/question-mark conventions correct

## 18. Direction/bidi
- 18.1 Correct document direction
- 18.2 Mixed Latin text safe in RTL
- 18.3 Phone/email readable
- 18.4 Selector handles mixed directions

## 19. Accessibility
- 19.1 Page lang correct
- 19.2 ARIA labels translated
- 19.3 Target names language-tagged
- 19.4 Focus/keyboard behavior preserved

## 20. Metadata/SEO readiness
- 20.1 Localized title/description
- 20.2 Correct hreflang target
- 20.3 Canonical strategy coherent
- 20.4 OG locale coherent

## 21. Social/share text
- 21.1 Share title natural
- 21.2 Share body natural
- 21.3 Preview alt natural
- 21.4 No English leakage

## 22. Interaction/status text
- 22.1 Copy success natural
- 22.2 Fallback instruction natural
- 22.3 Share fallback natural
- 22.4 No ambiguous action wording

## 23. Mobile text expansion
- 23.1 Hero fits
- 23.2 Service cards fit
- 23.3 Buttons fit
- 23.4 Language menu fits

## 24. Analytics/privacy invariance
- 24.1 Event names unchanged
- 24.2 Enums unchanged
- 24.3 No PII added
- 24.4 Language analytics bounded if added

## 25. Maintainability/regression
- 25.1 One source authority
- 25.2 All locale keys complete
- 25.3 Placeholders preserved
- 25.4 Tests fail closed on drift
